Automatize seu atendimento, reservas e pedidos com inteligência artificial

Por que isso é bom para o seu restaurante?
O n8n é a interface que conecta o Ajax (seu motor de IA) a tudo que seus clientes usam: WhatsApp, Instagram, Facebook, e-mail e site. Com essa integração, você atende 24h por dia, captura leads automaticamente e nunca perde uma reserva — sem contratar mais funcionários.

🚀 1. Instalação do n8n

O n8n é uma ferramenta de automação open-source. Você pode rodar via Docker:

docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

Acesse http://localhost:5678 no navegador.

Dica: Para produção, use o Docker Compose com PostgreSQL para persistir dados.

🔗 2. Conectando o Ajax ao n8n

O Ajax tem um endpoint HTTP que o n8n pode chamar via node HTTP Request:

POST http://localhost:8000/api/agent/chat
Content-Type: application/json

{
  "session_id": "restaurante-{{$node[\"Webhook\"].json[\"body\"][\"from\"]}}",
  "message": "{{$node[\"Webhook\"].json[\"body\"][\"message\"]}}"
}

⚡ 3. Fluxos Prontos para o Restaurante

🪑 Fluxo 1: Reserva Automática de Mesas

Gatilho: Cliente manda "Quero reservar uma mesa para 4 pessoas sábado às 20h"

O que acontece:

  1. Webhook captura a mensagem (WhatsApp/Instagram)
  2. Consulta API do Ajax para entender a intenção
  3. Verifica disponibilidade no Google Sheets/Calendly
  4. Confirma ou sugere outro horário
  5. Envia confirmação com QR Code da mesa

Ferramentas n8n usadas: Webhook → HTTP Request (Ajax) → Google Sheets → If → Respond to Webhook

💬 Fluxo 2: Atendimento Automático 24h

Gatilho: Qualquer mensagem fora do horário comercial

O que acontece:

  1. Webhook recebe mensagem
  2. HTTP Request envia para o Ajax com contexto do cardápio
  3. Ajax responde sobre: ingredientes, alergênicos, preços, promoções
  4. Se detectar intenção de pedido, redireciona para fluxo de Pedidos
  5. Se for dúvida simples, responde imediatamente

Ferramentas n8n usadas: Webhook → HTTP Request (Ajax) → Switch → Respond to Webhook

🥡 Fluxo 3: Pedido Online via WhatsApp

Gatilho: Cliente manda "Quer 1 pizza calabresa e 1 refrigerante"

O que acontece:

  1. Webhook recebe o pedido
  2. Ajax extrai itens, quantidades e endereço
  3. Calcula total com taxa de entrega
  4. Gera link de pagamento (Pix/Mercado Pago)
  5. Envia confirmação para cozinha (impressora ou tablet)

Ferramentas n8n usadas: Webhook → HTTP Request (Ajax) → Set → Mercado Pago API → Webhook Response
